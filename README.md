# Hotel Fazenda Fascinação — conceito de landing page

Proposta visual responsiva para apresentar uma direção possível para o site do Hotel Fazenda Fascinação, em Miguel Pereira, RJ.

## Visualizar

Abra `index.html` em um navegador. O projeto é estático e não requer instalação.

## Importante

Esta é uma demonstração de conceito. As fotografias são imagens ilustrativas de banco e devem ser substituídas por imagens próprias autorizadas do hotel. Informações sobre serviços, atividades, acomodações, avaliações, preços e contatos precisam ser confirmadas diretamente com o estabelecimento antes de qualquer publicação comercial. Os botões de contato direcionam para o Instagram público do hotel; não há motor de reservas.

## Arquivos

- `index.html`: estrutura e textos da landing page.
- `styles.css`: estilos responsivos e apresentação visual.
- `script.js`: menu móvel.
